Mouse Battery Indicator

必要な環境
Windows 10 / 11、.NET Framework 4.8

インストール版
1. GitHub の Releases から MouseBatteryIndicator-v1.0.0-Setup.exe をダウンロードします。
2. Setup.exe を開き、画面に従ってインストールします。
3. スタートメニューの「Mouse Battery Indicator」から起動できます。
管理者権限は不要です。インストール先は自分のユーザーフォルダーです。

ZIP版
ZIPをすべて展開して、MouseBatteryIndicator.exe を開きます。
ZIPの中から直接起動せず、先に展開してください。

使い方
・タスクバー右側の数字が残量（%）です。
・見つからない場合は「∧」を開き、数字をタスクバーへドラッグしてください。
・左クリックで機種名、残量、充電状態と、残量の推移グラフ（24時間／7日間）を表示します。
・右クリック →「表示するマウス」で対象を選択します。
・数字の下の緑の線は充電中です。
・右クリックから数字の色、太さ、更新間隔を変更できます。
・自動起動は、右クリック →「Windows 起動時に実行」で有効にできます。
・終了するときは、右クリック →「終了」を選びます。

対応機種
Razer の対応モデル、Logitech / ロジクール HID++ 2.0 の対応機種、
Windows が残量を公開する Bluetooth マウスで使えます。
Xenics TITAN GE AIR の取得処理も試験追加していますが、実機未確認です。
ファームウェアや接続方式によって取得できない可能性があります。
すべてのマウスや受信機に対応するわけではありません。
実機確認済みは Razer Viper V3 Pro の受信機接続です。
詳しい条件と機種一覧は README.md を参照してください。

残量が「--」の場合
マウスを動かし、右クリック →「今すぐ更新」を押してください。
数値ではなく段階だけを返す機種は、左クリックの詳細画面に段階を表示します。
取得できない場合は、右クリック →「診断結果を保存」で調査用のテキストを保存できます。

更新・削除
更新やアンインストールの前に、右クリック →「終了」でアプリを終了します。
インストール版は Windows の設定 →「アプリ」から削除できます。
ZIP版は自動起動をオフにしてアプリを終了し、展開したフォルダーを削除します。
設定と残量の記録は %LOCALAPPDATA%\MouseBatteryIndicator に保存されます。
旧版の設定は初回起動時に引き継ぎます。
アンインストール後も設定と記録は残ります。不要ならこのフォルダーを削除できます。
